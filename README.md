# Juego de mazmorra: motor 2D con pathfinding

Proyecto integrador de Estructuras de Datos, Temática A.

Un aventurero explora una mazmorra y recoge tesoros mientras unos monstruos lo persiguen.

## Requisitos

- Python 3.11 o superior
- pytest

## Instalar y ejecutar

```bash
pip install pytest
python main.py
python -m pytest
```

## Estructura

- `specs/`: artefactos SDD
- `estructuras/`: una estructura por módulo
- `dominio/`: lógica del juego
- `tests/`: pruebas con pytest
- `docs/`: informe y evidencias

## Código reutilizado

Parte de las estructuras se adapta de los laboratorios del curso (carpeta `Clase`, semanas 5 a 9). Cada archivo reutilizado dice su origen en el docstring inicial. La tabla completa está en `specs/00-producto/estructuras.md`.
